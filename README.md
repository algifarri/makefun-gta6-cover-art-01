VICEFRAME — Sunset Cover Studio. A static, fully offline web app that turns a person's own photos plus a caption into GTA-style multi-panel cover art: four panel layouts (Classic Grid, Triptych, Mosaic Six, Hero Poster) that adapt to square, portrait and landscape posts, per-panel photo framing (pick the photo, zoom, drag to reposition), editable title and subtitle in original Anton lettering, a sunset/neon Vice City grade with intensity control, and one-click PNG export at 1080×1080, 1080×1350 and 1920×1080 (or all three at once). Photos never leave the machine — there is no upload and no network request — and two built-in sample photos are included so anyone can make a cover immediately. Everything is original: no Rockstar logos, artwork or fonts.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 — or open app/index.html in a desktop browser
```
